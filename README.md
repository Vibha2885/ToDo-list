# ✅ To-Do List App (React)

A dynamic and responsive task management application built using **React.js**, designed to help users efficiently organize and track daily activities with real-time updates.

---

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* ❌ Delete tasks
* 🔄 Real-time UI updates using React state
* 📱 Responsive and user-friendly interface

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Language:** JavaScript (ES6+)
* **Styling:** CSS

---

## 📊 Project Highlights

* Implemented full **CRUD functionality** (Create, Read, Update, Delete)
* Managed application state using **React Hooks (useState)**
* Efficiently handles **50+ tasks** with smooth UI performance
* Built reusable components for better scalability
